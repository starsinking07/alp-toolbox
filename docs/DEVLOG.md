# 开发历程 (DEVLOG)

> 本仓库的 git 历史很浅: 项目公开前一直于本地开发, 经网页端上传发布。
> 为弥补"看不到迭代过程"的遗憾, 这里按时间线记录真实的开发里程碑 ——
> 每一条都有对应的产品产物或协议结论背书, 不注水。

本项目由作者 (苏晓沉) 与 AI 结对开发: 作者负责需求定义、硬件实验 (抓包、真机验证、
功耗实测) 与产品决策; AI 负责代码实现、抓包分析与文档整理。所有协议结论均以
USBPcap 抓包 + 真机实测双重验证, 详见 [PROTOCOL.md](../PROTOCOL.md)。

## 2026-10-02 — 协议逆向与第一版

- USBPcap 抓官方"装备箱"流量, 破解帧格式 `[A5][LEN][CMD][params][CK]` 与全部温控命令
  (0x24 固定转速 / 4 锚点曲线、0x25 状态、0x26 曲线槽位), 出厂曲线实测标定
- RGB 灯效 0x10–0x15 全量破解 (7 种模式 + 参数字段), 独立成 [LIGHTING.md](../LIGHTING.md)
- 转速物理上限实测 ~4700 RPM (固件钳 100% PWM); 功耗计实测四档功耗曲线 (1.5W→10.6W)
- USB (libusb) / 蓝牙 BLE (bleak) 双通道 + 自动切换; PyInstaller 打包

## 2026-10-03 — 屏幕图传攻坚 (全项目最难的一战)

- 0x07 主机参数推送破解, 散热器屏幕参数页从"陈旧缓存"变实时
- 图片上传协议: 30+ 次对照实验后破解 0x0C 拒绝根因 —— 设备每跨 4096B flash 页边界
  需 ~40ms 排空, 全图 29 处停顿; **均匀速率必败**, 字节级对齐官方抓包时序后 2096 帧全绿
- 画布定案 428×142 RGB565 大端 + 元数据 CRC16-XMODEM; 尾帧短块 (48B) 结构
- 任意 PNG/JPG 上屏通路打通 (构建器与官方抓包逐字节自检), GUI 选图/预览/进度/取消

## 2026-10-04 — 产品化与全项目审计

- 屏幕信息卡 (CPU/GPU 型号 + 日期) / 情境卡片 (全屏游戏卡 / ≥85°C 警报卡) / 档位双向同步
- 托盘常驻 / 单实例守卫 / 任务队列化 / 平滑档位映射 (L1→L4)
- 全项目五路并行代码审计, 修复约 50 项: 配置原子写、温度尖峰过滤锁死、上传 C4 应答校验、
  传输层线程泄漏、深色主题残留等
- NSIS 安装包 (集成 PawnIO 驱动静默安装); 应用内检查更新

## 2026-10-05 — 打磨与开源

- 深色模式三轮完善: 弹层容器 / 滚动视口 / 标题栏徽章 / 应用级调色板兜底
- 档位记忆 (智能变频开关前后的档位自动恢复); 开机自启动任务计划化 (静默提权免 UAC)
- 应用内更新下载 404 根治 (expanded_assets 解析真实附件直链, 绕开中文文件名改写)
- 开机自启动可静默驻留托盘 (任务计划带 --tray, 「启动后最小化到托盘」开关)
- 档位模型简化定案: 工具箱是唯一权威, 物理按钮换档被当前模式输出接管
  (不再做双向同步状态机 — 该特性三轮修补后由用户定案移除)
- 本仓库公开, 转入常规 git 流程 (Conventional Commits)

## 工程约定

- 协议结论只从抓包来, 不凭猜测修改 —— 非法帧会写坏设备 flash 导致开机循环
- 每次发布前跑离线自检套件 (含与官方抓包逐字节比对的构建器自检)
- UI / 主题类改动用离线探针逐像素验收 (截图抓色断言)
